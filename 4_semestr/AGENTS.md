# AGENTS.md

## Purpose
Локальные инструкции для Codex в этом проекте.

## Workflow
- Сначала читать этот файл перед изменениями кода.
- Для поиска использовать `rg` (или альтернативу, если недоступен).
- Перед правками кратко формулировать план.
- После правок запускать релевантные проверки (тесты/линтер/сборка), если доступны.

## Editing Rules
- Не делать деструктивные git-операции без явного запроса.
- Не откатывать чужие изменения в рабочем дереве.
- Изменения делать минимально необходимыми для задачи.

## Communication
- Отвечать кратко и по делу.
- В отчете указывать: что изменено, где, как проверено, что осталось.
